Settings

Keys are saved in this browser only. Nothing is committed to your repository and nothing is sent anywhere except the service it belongs to.

API keys

A free Twelve Data key powers the weekly, monthly, 6-month and 1-year returns — Finnhub's free tier only gives today's move. Grab one at twelvedata.com. Sports data needs no key.

Weather

Open-Meteo needs no API key — the free endpoint is unauthenticated. Change the location by editing latitude and longitude, or build a new URL at open-meteo.com/en/docs. Refreshes at 6am, noon, 3pm, 6pm and 10pm.

Movies

Rotten Tomatoes has no public API. The movie AD reads its score from OMDb instead — a free key, 1,000 lookups a day, cached per film forever. Without it the AD shows one fewer rating rather than an error. Letterboxd's own average comes through the scrape proxy below.

Letterboxd publishes no watchlist API and GitHub Pages cannot read letterboxd.com directly — the browser blocks it. Point this at the same Cloudflare Worker as Fantasy (redeploy it after this update; it now forwards /letterboxd/*) and the watchlist and recent-diary feed are both read server-side. With no proxy set, use Import watchlist CSV on the Movies tab instead: Letterboxd → Settings → Data → Export.

Menu

The backlog in data/recipes.json is baked by node tools/build-recipes.js and needs nothing at run time. The proxy is only for + Add by link: a browser on GitHub Pages cannot read another site’s page directly. Point it at the same Cloudflare Worker as Fantasy and Letterboxd — redeploy it after this update, it now forwards /recipe?url=…. Leave it blank and only sites that publish CORS headers will import.

Theme

Paints the deck in a followed team's colours as though they were playing today, whatever the schedule says. Set it back to Off to go back to the real one.

Weather effects

Snow settles on the panels, rain leaves a puddle across the bottom, sun throws a lens flare, wind leans everything on screen and a storm flashes. Each one follows the actual forecast. Tick any below and only those run, so a storm can be tested without the afternoon sun still blazing through it — untick them all to go back to the real weather.

Kiosk rotation

What AUTO cycles through. Switching one off drops both its tab and its full-screen AD; Weather is an AD only, To Do is a tab only.

Kiosk previews

Pick a film and the Movies preview is about that one — the way to see a gold screen or a poop sticker without waiting for the right film to come round. Leave it on Random and the AD chooses for itself.

Opens one full-screen AD and holds it there — no rotation, no timer — so it can be styled without waiting for its slot. Close with the ✕ or Escape. Works whether AUTO is on or off; from the console it is Kiosk.previewAd('sports').
